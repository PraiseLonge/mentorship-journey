# week 1: Environment Setup
## Overview
This week focused on setting up the java development environment.
## Tools Used
- Java Development Kit (JDK)21
- IntelliJ IDEA
- Windows PowerShell
## HelloWorld Program
The program prints "Hello, world!" to the console.
## How to Run

Run:
java HelloWorld
